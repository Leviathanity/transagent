# pdf-translator Test Plan

> **Objective:** Verify each pipeline stage produces correct output using real CLI subcommands against `test/test1.pdf` (33-page automotive quality handbook).

## Test Cases

| # | Test | CLI Command | Expected Output | Verification |
|---|------|-------------|-----------------|-------------|
| T1 | Help & Usage | `ptl` | Print all subcommands | Check stdout |
| T2 | Environment Check | `ptl check` | Print Bun/MarkItDown/Python/API Key status | Check stdout |
| T3 | Stage 1: Convert | `ptl convert test/test1.pdf --output test/T3_output.md` | 85KB+ Markdown file | File exists, non-empty, contains text from PDF |
| T4 | Stage 1: Print mode | `ptl convert test/test1.pdf` | Markdown content to stdout | Non-empty stdout |
| T5 | Review Spec Check | Check `specs/review-conversion.md` | 8 review categories | Parse categories, verify count >= 8 |
| T6 | Stage 2: Review (Grill only) | `ptl review test/T3_output.md --spec specs/review-conversion.md --output test/T6_reviewed.md --report test/T6_report.md` | Reviewed MD + report file | Report contains issues, output file exists |
| T7 | Review Report Content | Read `test/T6_report.md` | Detailed issues per category | Check for error/warning entries |
| T8 | Format Spec Check | Check `specs/review-formatting.md` | 11 review categories | Parse categories, verify count >= 8 |
| T9 | Pipeline: Full translate | `ptl translate test/test1.pdf --skip-interact --direction en2zh` | All 5 stages run, final output | Check workdir intermediate files |
| T10 | Pipeline: direction auto-detect | `ptl translate test/test1.pdf --skip-interact` | Direction detected and confirmed | Uses confirm prompt |

## Execution Order

T1 → T2 → T3 → T4 → T5 → T6 → T7 → T8 → T9 → T10

**Pre-requisite:** DEEPSEEK_API_KEY must be set for T6, T7, T9, T10.
