# 翻译后排版审查规范

## 1. 中英文长度适配

英→中（文字通常缩短约 30-50%），中→英（文字通常增长约 30-50%）。

- [ ] 表格列宽已根据译文重新调整，无单元格溢出或大量留白
- [ ] 列表项文本对齐不受长度变化影响
- [ ] 原文中的视觉换行不被强制保留，已按语义重排
- [ ] 无因变长导致的页面溢出（如超长行）

## 2. 段落完整性

- [ ] 翻译后段落未被意外拆分（原文一段 → 译文一段）
- [ ] 翻译后段落未被意外合并（原文多个段落未被粘合）
- [ ] 段落间空行数与原文一致（通常一个空行分隔）
- [ ] 空段落（如视觉分隔符）被保留

## 3. 表格排版

- [ ] 表格分隔线 `|---|---|` 列数匹配表头
- [ ] 表格分隔线每列长度与对应列表头/内容对齐（美观）
- [ ] 表头翻译后，分隔线已重新对齐
- [ ] 单元格内换行控制在合理范围（不因单个长词打破表格）

## 4. 标题格式

- [ ] 标题 `#` / `##` / ... 后有一个空格
- [ ] 标题层级关系与原文一致
- [ ] 标题中的术语已正确翻译
- [ ] 无多余或缺失的标题标记

## 5. 代码块与内联代码

- [ ] 代码块内容未被翻译（保持原文）
- [ ] 代码块语言标记 ` ```python ` 等已保留
- [ ] 内联代码反引号配对正确，无遗漏
- [ ] 代码块边界无多余空白行或缺失空白行

## 6. 列表格式

- [ ] 列表标记符（`-` / `*` / `+` / `1.`）格式统一
- [ ] 列表缩进层级保留，与原文一致
- [ ] 嵌套列表的缩进空格数全文统一（2 或 4 空格）
- [ ] 列表项后是否有空行，全文一致

## 7. 引用块

- [ ] 引用块标记 `>` 缩进层级正确
- [ ] 多行引用每行 `>` 符号保留
- [ ] 引用块与正文间有适当空行分隔

## 8. 链接与图片

- [ ] 链接文本已翻译，URL 完整保留
- [ ] 图片引用语法 `![alt](url)` 无损
- [ ] 图片 alt 文本已翻译（如有意义）
- [ ] 锚点/书签引用保持一致（如 `[见第3节](#section-3)`）

## 9. 空白与缩进

- [ ] 全文缩进风格统一（2 空格 或 4 空格）
- [ ] 行尾无多余空格（trailing spaces）
- [ ] 文件末尾有且仅有一个空行
- [ ] 无 Tab 和空格混用

## 10. 特殊符号与标点

- [ ] 中英文标点规则正确：
  - 中文使用全角标点（，。！？）
  - 英文使用半角标点（, . ! ?）
  - 中英文混排的间隔合理
- [ ] 破折号、省略号、引号风格统一
- [ ] 单位前空格处理一致（如 "5 kg" vs "5kg"）
- [ ] 数字与中文混排的间距处理一致

## 11. 翻译一致性

- [ ] 同一术语全文翻译一致（对照术语表）
- [ ] 同一短语结构翻译一致
- [ ] 数字、日期、单位格式符合目标语言习惯
- [ ] 专有名词（人名、地名、机构名）处理一致

## 审查输出格式

每个发现的问题按以下格式记录：

```
[严重度] 类别 - 位置
描述: ...
建议修复: ...
```

严重度定义：
- **error**: 必须修复（排版破坏、格式丢失、不可读）
- **warning**: 建议修复（格式不一致、可读性下降）
- **info**: 可忽略（轻微偏差，可接受）
