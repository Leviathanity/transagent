# PDF → Markdown 转换质量审查规范

## 1. 编码与乱码

- [ ] 全文无不正常字符（乱码、控制字符、私有区字符）
- [ ] 特殊符号完整保留（单位符号 °Ωμ、数学符号 ∑∫∞、版权符号 ©®™）
- [ ] Unicode 字符正确呈现（CJK 扩展字符、emoji、变音符号）
- [ ] 引号正确转换为标准 Markdown 引号或保留原文形式
- [ ] 破折号（—/–）、省略号（…）正确保留

## 2. 标题层级

- [ ] H1-H6 层级连续，无跳级（不允许 H1→H3 中间缺 H2）
- [ ] 标题文本完整，无截断、无跨页拆分
- [ ] 文档有且仅有一个 H1（文档标题）
- [ ] 无将正文段落、列表项、表格标题错误识别为 Markdown 标题
- [ ] 数字编号标题（如 1.1、1.2.3）格式正确

## 3. 表格完整性

- [ ] 表格行列数正确，无缺列或多列
- [ ] 表格对齐线 `---|---|` 列数与表头一致
- [ ] 合并单元格情况被标注或合理展平
- [ ] 空单元格有占位内容，不被跳过
- [ ] 无将表格内容展平为纯文本段落
- [ ] 无边框表格（borderless table）被正确识别并构建为 Markdown 表格

## 4. 列表结构

- [ ] 有序列表编号连续（1, 2, 3...）
- [ ] 无序列表嵌套层级正确（最多 4 层）
- [ ] 列表项内容完整，无跨项合并或缺失
- [ ] 列表缩进一致（全文统一 2 或 4 空格）
- [ ] 列表不包含不属于它的段落

## 5. 段落连续性

- [ ] 跨页断行的段落已合并为一段
- [ ] 无多余空行（连续 3 个及以上空行视为异常）
- [ ] 无丢失的段落（对比原文页数/段落数估算）
- [ ] 段落首行缩进处理一致

## 6. 特殊元素

- [ ] 图片引用保留（格式：`![描述](path)` 或 `[IMAGE: 描述]`）
- [ ] 代码块起止边界 ` ``` ` 正确配对
- [ ] 内联代码 `` ` `` 符号配对正确
- [ ] 代码块语言标记保留（````markdown ````python 等）
- [ ] 引用块 `>` 嵌套层级正确
- [ ] 脚注/尾注引用和定义关联正确
- [ ] 超链接 `[text](url)` 语法完整

## 7. 污染内容

- [ ] 无页眉文字混入正文（如章节名、文档标题重复出现）
- [ ] 无页脚/页码残留（如 "Page 1 of 10"、"- 1 -"）
- [ ] 无水印文字混入（如 "DRAFT"、"CONFIDENTIAL"）
- [ ] 无 PDF 元数据残留（路径、文件名、创建日期）

## 8. 数学公式（如有）

- [ ] LaTeX 数学公式 `$$...$$` 或 `$...$` 完整保留
- [ ] 公式无截断或乱码
- [ ] 行内公式与行间公式区分正确

## 审查输出格式

每个发现的问题按以下格式记录：

```
[严重度] 类别 - 位置
描述: ...
建议修复: ...
```

严重度定义：
- **error**: 必须修复（数据丢失、结构破坏、无法阅读）
- **warning**: 建议修复（格式偏差、可读性下降）
- **info**: 可忽略（轻微偏差，不修复也可接受）
